자주 묻는 질문

카톡 단톡방 공지 확인 안 한 사람을 어떻게 찾나요?

TalkCheck에 카카오톡 대화 내보내기 .txt 파일을 올리고, 공지 키워드(예: "공지", "필독")를 입력하면 됩니다. 공지 메시지 이후 아무 말도 하지 않은 멤버를 자동으로 추려서 @멘션 문자까지 만들어 드립니다.

개인정보가 서버로 전송되나요?

전혀 없습니다. 파일 분석은 내 브라우저 안에서만 이루어집니다. 업로드 버튼이 없고, 서버도 없습니다. 카카오톡 대화 내용은 어디에도 저장되거나 전송되지 않습니다.

어떤 파일 형식을 지원하나요?

카카오톡 iOS 내보내기와 Android 내보내기 .txt 파일 두 가지를 모두 지원합니다. 파일을 올리면 형식을 자동으로 감지합니다.

iOS에서 카카오톡 대화를 내보내려면 어떻게 하나요?

단톡방 오른쪽 위 메뉴 → '대화 내용' → '내보내기' → '파일로 저장'. 자세한 방법은 내보내기 가이드를 참고하세요.

Android에서 카카오톡 대화를 내보내려면 어떻게 하나요?

단톡방 오른쪽 위 메뉴 → '채팅방 설정' → '대화 내용 내보내기' → '텍스트 파일로 내보내기'. 자세한 방법은 내보내기 가이드를 참고하세요.

멤버 이름이 잘못 나올 수 있나요?

카카오톡 대화 파일에 저장된 표시 이름 기준입니다. 상대방이 내 연락처에 저장한 이름과 카톡 프로필 이름이 다를 경우, 파일에 기록된 이름이 우선됩니다.

공지자 본인도 무응답자에 포함되나요?

아닙니다. 공지를 보낸 사람은 자동으로 제외합니다.

10MB보다 큰 파일도 되나요?

네. 대용량 파일도 브라우저 내부에서 처리하므로 제한이 없습니다. 단, 브라우저 메모리에 따라 속도가 달라질 수 있습니다.

무료인가요?

완전 무료입니다. 로그인도 없고, 설치도 없습니다.

스터디·동아리·직장 단톡에서도 쓸 수 있나요?

네. 카카오톡 단체 대화방이라면 어디서든 사용 가능합니다. 키워드를 '필독', '공지', '확인 요망' 등 원하는 단어로 자유롭게 설정하세요.

☕ 서비스가 도움이 됐다면 토스로 커피 한 잔 사 주시면 감사합니다!

더 궁금한 점은 GitHub Issues로 남겨주세요.
