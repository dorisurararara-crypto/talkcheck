# 카카오톡 대화 내보내기 방법

## iOS (아이폰)

1. 카카오톡 단체 채팅방 열기
2. 우측 상단 **햄버거 메뉴(≡)** 탭
3. **설정(⚙️)** → **대화 내용 내보내기**
4. **파일로 저장** 선택
5. 저장된 `.txt` 파일을 TalkCheck에 업로드

## Android (안드로이드)

1. 카카오톡 단체 채팅방 열기
2. 우측 상단 **⋮ (더보기)** 탭
3. **채팅방 서랍** → **채팅방 관리**
4. **대화 내용 내보내기** → **파일로 저장**
5. 저장된 `.txt` 파일을 TalkCheck에 업로드

## 주의사항

- 내보내기 파일은 기기에서만 처리됩니다. 서버로 전송되지 않습니다.
- 파일 크기는 수십MB까지 처리 가능합니다.
- iOS와 Android 형식 모두 자동 감지됩니다.
