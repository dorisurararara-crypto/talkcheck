학부모 단톡방 공지 확인 안 한 분 찾기
10초 만에 @멘션 명단 완성

학교·학원 학부모 단체 카카오톡방 담당자라면 공감하는 상황이 있습니다. 소풍 준비물, 급식비 납부, 방과후 수업 신청 등 중요한 공지를 올렸는데 일부 학부모가 반응하지 않습니다. 누가 확인했는지 직접 스크롤하며 하나하나 파악하다 보면 20~30명짜리 방에서도 10분이 훌쩍 넘습니다.

TalkCheck는 카카오톡 대화 내보내기 txt 파일 하나만으로 공지 미확인 학부모 명단과 @멘션 텍스트를 자동 생성합니다. 모든 처리는 브라우저 안에서만 이뤄지고 서버로 전송되는 데이터는 없습니다.

✅ 설치 불필요  ·  무료  ·  개인정보 서버 전송 없음  ·  iOS/Android 모두 지원

사용 방법 (4단계)

  1. 대화 내보내기 — 학부모 단체방 열기 → 우측 상단 ≡ → 채팅방 서랍 → 대화 내보내기 → txt 파일 저장
  2. TalkCheck 접속 — TalkCheck 열기 → txt 파일 드래그&드롭
  3. 공지 키워드 입력 — 공지문에 포함된 핵심 단어 입력 (예: "급식비", "소풍", "내일 준비물")
  4. 멘션 복사 후 발송 — 자동 생성된 @멘션 텍스트를 단톡방에 붙여넣기

개인정보는 안전한가요?

TalkCheck는 100% 브라우저 내에서 처리합니다. 대화 내용이나 학부모 이름이 외부 서버로 전송되지 않으며, 페이지를 닫으면 데이터가 자동 삭제됩니다. 학부모 개인정보를 외부에 노출하지 않아도 됩니다.

얼마나 빠른가요?

파일 업로드부터 @멘션 텍스트 완성까지 보통 10초 이내입니다. 200명 이상 대형 단체방 파일도 처리 가능합니다.
