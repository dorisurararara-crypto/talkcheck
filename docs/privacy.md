# 개인정보 처리방침

**최종 업데이트**: 2026년 5월

## 1. 수집하는 정보

TalkCheck는 다음 정보만 수집합니다:

- **GoatCounter 분석**: 페이지뷰 수, 이벤트 이름(예: file_parsed, result_copied). 메시지 내용은 포함되지 않습니다.

## 2. 수집하지 않는 정보

- 업로드한 채팅 파일 내용
- 채팅 메시지 텍스트
- 참여자 이름
- 개인 식별 정보

## 3. 파일 처리 방식

업로드된 채팅 파일은 **브라우저 내에서만** 처리됩니다. 서버로 전송되지 않습니다.

## 4. 쿠키

필수 기능을 위해 `localStorage`에 마지막 키워드를 저장합니다. 브라우저 설정에서 삭제 가능합니다.
