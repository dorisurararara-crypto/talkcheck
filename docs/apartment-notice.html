무응답자 찾기
10초 만에 미확인 세대 명단 완성

아파트 입주자대표회의나 반상회 단체방을 운영하다 보면 관리비 고지, 공사 안내, 주민총회 일정 등 중요한 공지에 반응하지 않는 세대가 생깁니다. 직접 채팅을 스크롤하며 누가 확인했는지 파악하는 작업은 시간이 많이 걸리고 빠뜨리기도 쉽습니다.

TalkCheck를 사용하면 카카오톡 단체방 대화 내보내기 txt 파일 하나만으로 공지 미확인 세대 명단과 @멘션 텍스트를 자동으로 만들 수 있습니다. 별도 설치 없이 브라우저에서 바로 실행되며, 채팅 내용은 서버로 전혀 전송되지 않습니다.

✅ 설치 불필요  ·  무료  ·  대화 내용 외부 전송 없음  ·  iOS/Android 모두 지원

사용 방법 (4단계)

  1. 대화 내보내기 — 입주자 단체방 열기 → ≡ 메뉴 → 채팅방 서랍 → 대화 내보내기 → txt 파일 저장
  2. TalkCheck 접속 — TalkCheck 열기 → txt 파일 드래그&드롭
  3. 공지 키워드 입력 — 공지문의 핵심 단어 입력 (예: "관리비", "주민총회", "엘리베이터 공사")
  4. 멘션 복사 후 발송 — 생성된 @멘션 텍스트를 단체방에 붙여넣기

입주자 개인정보 처리

TalkCheck는 업로드된 txt 파일을 외부 서버로 보내지 않습니다. 모든 분석은 사용자 기기의 브라우저 안에서만 처리되며, 탭을 닫으면 데이터가 남지 않습니다. 입주자 이름·대화 내용이 외부에 노출될 우려가 없습니다.

대형 단체방도 가능한가요?

네. 300명 이상 입주자 대형 단체방 파일도 처리 가능합니다. 파일 크기가 클수록 분석 시간이 약간 늘어나지만 일반적으로 1분 이내에 완료됩니다.
