카톡 단톡방 공지 확인 안 한 사람
찾는 방법 비교

50명짜리 단톡방에서 공지에 반응 없는 멤버를 찾으려면 얼마나 걸릴까요? 현실적인 방법 5가지를 비교했습니다.

방법별 비교표

방법 소요 시간 (50명 기준) 정확도 비용
① 수동 스크롤 확인 20~40분 낮음 (빠진 사람 놓침) 무료
② 스크린샷 + 이름 옮겨 적기 15~25분 중간 (실수 가능) 무료
③ 엑셀/노션 수동 정리 30분 이상 (초기 세팅 포함) 높음 무료 (시간 비용 큼)
④ 카카오톡 공식 기능 — — 없음 (기능 미제공)
⑤ TalkCheck 추천 10~30초 높음 (자동 추출) 무료, 서버 없음

① 수동 스크롤 확인 — 가장 흔한 방법

공지 메시지를 보낸 뒤 채팅방 상단으로 스크롤해서 각 멤버의 이름을 하나씩 확인합니다. 50명이 넘는 방에서는 스크롤 도중 메시지가 밀려 처음부터 다시 확인해야 하는 경우가 자주 생깁니다.

문제: 이름이 비슷하거나 닉네임이 자주 바뀌는 경우 누락이 많습니다. 확인 결과를 따로 기록하지 않으면 재확인이 불가능합니다.

② 스크린샷 + 이름 옮겨 적기

멤버 목록 스크린샷을 찍고 응답 메시지와 대조합니다. 50명 이상이면 스크린샷만 3~5장이 필요합니다. 이름을 직접 타이핑하면 오탈자가 나고, 완성된 @멘션 문자를 다시 정리해야 합니다.

③ 엑셀/노션 수동 정리

단톡방 멤버 목록을 스프레드시트에 미리 입력해두고, 응답자를 체크합니다. 초기 세팅에 30분 이상이 필요하고, 멤버가 바뀔 때마다 업데이트해야 합니다. 반복적으로 공지를 보내는 경우에는 유용하지만, 1~2회성 확인에는 과합니다.

④ 카카오톡 공식 기능 — 없음

카카오톡은 2026년 현재 단체방 공지에 대한 개별 읽음 확인 기능을 제공하지 않습니다. "공지" 기능은 메시지를 고정할 뿐, 누가 확인했는지는 알 수 없습니다.

⑤ TalkCheck — 대화 내보내기 파일로 10초 해결

카카오톡 대화 내보내기(.txt) 파일을 TalkCheck에 올리면, 공지 키워드를 검색해 응답하지 않은 멤버 목록과 바로 붙여넣기 가능한 @멘션 문자를 자동으로 만들어줍니다.

  • 서버에 데이터 전송 없음 — 브라우저 안에서만 처리
  • iOS·Android 내보내기 형식 모두 지원
  • 완전 무료, 설치 불필요

대화 내보내기 방법

카카오톡 단체방 → 오른쪽 상단 메뉴(≡) → 대화 내보내기 → 텍스트 파일(.txt) 선택 → TalkCheck에 파일 업로드.

자세한 방법은 iOS/Android 내보내기 가이드를 참고하세요.
