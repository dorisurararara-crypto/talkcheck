iOS / Android 내보내기 (.txt) 지원

채팅 내보내기 방법 보기
  1. iOS: 채팅방 → 우측 상단 메뉴 → 대화 내용 내보내기 → 파일로 저장
  2. Android: 채팅방 → 우측 상단 ⋮ → 채팅방 서랍 → 채팅방 관리 → 대화내용 내보내기

2. 공지 키워드 입력

입력한 키워드가 포함된 첫 메시지를 공지로 인식합니다
